# Binning Methods

This package implements methods explored in the [Binning Methods paper](https://doi.org/10.1101/2025.06.26.661884). 

It contains functions for: 
- Binning including utilities for counting members of each Bin, combining bins, transformation binning
- Bin weights 
- Harpoon sampling
- Data Splitting: Random, Window, Stratified, Akin Split (and Akin Scorer)

Find Epoch Sampling and Bin metrics (aka Bin loss) in [poseigen_trident](https://github.com/Husam94/poseigen_trident). They are moved there 

Binning methods are exemplified in two case studies: [synthetic data](https://github.com/Husam94/SynthSkew) and [YY1-DNA interactions](https://github.com/Husam94/YY1)
